# 說明

**Lumidepth Player VR** 可在 Meta Quest 上播放存放於 PC 或家用 NAS 中的 VR180、VR360 及 2D 影片。AI 模型會逐格估算深度，因此轉動頭部時，遠近物體會自然地產生位移。

## 系統需求

- Windows 10 / 11（64 位元）
- NVIDIA GeForce RTX 3060 或更新（RTX 30 / 40 / 50 系列）
- 透過 Meta Quest Link（傳輸線）或 Air Link 連線的 Meta Quest 頭戴裝置
- 影片：MP4、MKV、MOV、WebM。H.265（HEVC）、H.264（最高 4K）、AV1、VP9、ProRes
- 8 至 12 位元，4:2:0 / 4:2:2 / 4:4:4，HDR（HDR10、HLG）。HDR 影片會以 SDR 顯示
- 在 RTX 30 / 40 系列上，4:2:2 與 ProRes 由 CPU 解碼，因此 8K 60 fps 可能會跟不上（RTX 50 系列由 GPU 解碼）
- 3D 電影：左右並排、畫面循序 3D、空間影片（MV-HEVC）與藍光 3D（MKV 格式的 MVC）。會自動辨識，並以 3D 顯示在您面前的螢幕上。藍光 3D 由 CPU 解碼（需要支援 AVX2 的 CPU，否則以 2D 播放）

## 開始使用

1. 在 PC 上啟動 Meta Quest Link 應用程式，並透過 Link 或 Air Link 連線 Quest。
2. 在 Quest 的應用程式庫中啟動 Lumidepth Player VR。
3. 列表中會顯示 PC 的磁碟機。若要瀏覽 NAS 的共用資料夾，請先在 Windows 中將其對應為網路磁碟機。若要播放家用網路中的媒體伺服器（DLNA），請在列表中選擇「媒體伺服器（DLNA）」。
4. 用右扳機選擇影片即可開始播放。首次使用 3D 時，系統會針對您的 PC 準備 AI，可能需要幾分鐘（之後即可立即使用）。

## 操作方式

| 按鈕 | 列表 | 播放中 |
|---|---|---|
| 右扳機 | 選擇 / 按住並移動可捲動 | 顯示播放列 / 按下按鈕 |
| A | 上一層 | 返回列表 |
| B | 上一層 | 切換 3D 開/關 |
| Y | – | 播放 / 暫停 |
| X | – | 顯示 / 隱藏狀態列 |
| 右搖桿左/右 | – | −10 秒 / +10 秒 |
| 左搖桿左/右 | – | −60 秒 / +60 秒 |
| 按下右搖桿 | – | 重設正前方 |
| 按住右握把並移動 | – | 旋轉影片 |

## 播放列與設定

播放中扣下右扳機，即可在指向的位置顯示播放列。播放列包含音量、縮放、3D 開/關、重設正前方及設定（⚙）。

設定面板共有三個頁面：

- **顯示**：亮度、清晰度、反鋸齒
- **3D**：3D 深度、邊緣對齊、邊緣、空隙填補、防抖、更新頻率、視窗、2D/單畫面也轉 3D
- **格式**：投影（180°、360°、平面）與排列（左右、上下、單畫面）。會依據檔名與長寬比自動判斷；只有在畫面看起來不對時才需要手動選擇（僅套用於目前的影片）。

深度效果最適合左右並排的 VR180 影片。

## 疑難排解

- **「Meta Quest 未連線。」**：請透過 Link 或 Air Link 連線 Quest 後再試一次。
- **「找不到 NVIDIA GPU（GeForce RTX 30 系列或更新）。」**：請更新 NVIDIA 驅動程式。需要 RTX 30 系列或更新的 GPU。
- **3D 顯示「無法使用」**：GPU 記憶體可能不足。請關閉其他應用程式。
- **畫面看起來重疊或被分割**：請在設定的「格式」頁面中選擇投影與排列。
