# ヘルプ

**Lumidepth Player VR** は、PC や家の NAS にある VR180・VR360・2D の動画を Meta Quest で見るためのプレイヤーです。動画の 1 コマごとに AI が奥行きを推定し、頭を動かすと手前と奥がずれて見えるようにします。

## 動く環境

- Windows 10 / 11（64 ビット）
- NVIDIA GeForce RTX 3060 以降（RTX 30・40・50 シリーズ）
- Meta Quest シリーズを Meta Quest Link（ケーブル）または Air Link で PC につないで使用
- 動画: MP4・MKV・MOV・WebM。H.265（HEVC）・H.264（4K まで）・AV1・VP9・ProRes
- 8〜12 ビット、4:2:0・4:2:2・4:4:4、HDR（HDR10・HLG）。HDR は SDR に直して表示します
- 4:2:2 と ProRes は、RTX 30・40 シリーズでは CPU で復号します。8K 60fps は追いつかないことがあります（RTX 50 シリーズは GPU で復号）
- 3D 映画: 左右並び・交互の 3D（フレームシーケンシャル）・空間ビデオ（MV-HEVC）・ブルーレイ 3D（MVC を MKV にしたもの）。自動で見分けて、正面の画面に立体で出します。ブルーレイ 3D は CPU で復号します（AVX2 のある CPU が必要。無いときは 2D で再生）

## 始め方

1. PC で Meta Quest Link のアプリを起動し、Quest を Link か Air Link でつなぎます。
2. Quest の中のライブラリから Lumidepth Player VR を起動します。
3. 一覧に PC のドライブが出ます。NAS の共有フォルダは、Windows で「ネットワーク ドライブの割り当て」をしておくと一覧に出ます。家のメディアサーバー（DLNA）は、一覧の「メディアサーバー（DLNA）」を選ぶと探して出します。
4. 動画を右トリガーで選ぶと再生が始まります。初めて立体を使うときは、この PC 向けに AI を準備するので数分かかることがあります（2 回目からはすぐです）。

## コントローラ

| ボタン | 一覧 | 再生中 |
|---|---|---|
| 右トリガー | 指したものを選ぶ・押したまま上下でスクロール | 再生バーを出す／指したボタンを押す |
| A | 1 つ上のフォルダへ | 一覧へ戻る |
| B | 1 つ上のフォルダへ | 立体の入／切 |
| Y | – | 再生／一時停止 |
| X | – | 状態の行を出す／消す |
| 右スティック 左右 | – | −10 秒／＋10 秒 |
| 左スティック 左右 | – | −60 秒／＋60 秒 |
| 右スティック押し込み | – | 正面を直す |
| 右グリップを握って動かす | – | 動画の向きを変える |

## 再生バーと設定

再生中に右トリガーを引くと、指した所に再生バーが出ます。音量・拡大・立体の入切・正面を直す・設定（⚙）のボタンがあります。

設定の板は 3 枚です。

- **表示**: 明るさ・解像感・アンチエイリアス
- **立体**: 立体の強さ・輪郭合わせ・縁・隙間の埋め方・揺れ止め・更新の回数・窓・平面や 1 枚撮りの動画も立体にする
- **形式**: 投影（180°・360°・平面）と並び（左右・上下・1 枚）。ふだんはファイル名と縦横比から自動で決めます。合っていないときだけ手で選んでください（開いている動画だけに効きます）

立体の効果は、左右並びの VR180 の動画で最もよく効きます。

## うまくいかないとき

- **「Meta Quest が PC につながっていません」と出る**: Quest を Link か Air Link でつないでから、もう一度開いてください。
- **「NVIDIA の GPU が見つかりませんでした」と出る**: NVIDIA のドライバを最新にしてください。RTX 30 シリーズ以降が必要です。
- **立体が「使えません」と出る**: GPU のメモリが足りないことがあります。ほかのアプリを閉じてください。
- **形式が違って見える（左右が二重・上下に分かれる）**: 設定の「形式」で投影と並びを選んでください。
