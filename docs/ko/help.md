# 도움말

**Lumidepth Player VR**은 PC나 집의 NAS에 저장된 VR180, VR360, 2D 동영상을 Meta Quest에서 재생하는 플레이어입니다. AI 모델이 프레임마다 깊이를 추정하므로, 머리를 움직이면 가까운 물체와 먼 물체가 자연스럽게 어긋나 보입니다.

## 사용 환경

- Windows 10 / 11 (64비트)
- NVIDIA GeForce RTX 3060 이상 (RTX 30 / 40 / 50 시리즈)
- Meta Quest Link(케이블) 또는 Air Link로 연결한 Meta Quest 헤드셋
- 동영상: MP4, MKV, MOV, WebM. H.265 (HEVC), H.264 (4K까지), AV1, VP9, ProRes
- 8~12비트, 4:2:0 / 4:2:2 / 4:4:4, HDR (HDR10, HLG). HDR 동영상은 SDR로 표시됩니다
- RTX 30 / 40 시리즈에서는 4:2:2와 ProRes를 CPU로 디코딩하므로 8K 60fps는 따라가지 못할 수 있습니다 (RTX 50 시리즈는 GPU로 디코딩합니다)

## 시작하기

1. PC에서 Meta Quest Link 앱을 실행하고 Link 또는 Air Link로 Quest를 연결합니다.
2. Quest의 라이브러리에서 Lumidepth Player VR을 실행합니다.
3. PC의 드라이브가 목록에 표시됩니다. NAS의 공유 폴더를 보려면 Windows에서 네트워크 드라이브로 연결해 두세요.
4. 오른쪽 트리거로 동영상을 선택하면 재생이 시작됩니다. 3D를 처음 사용할 때는 PC에 맞춰 AI를 준비하므로 몇 분 걸릴 수 있습니다 (다음부터는 바로 시작됩니다).

## 재생 바와 설정

재생 중에 오른쪽 트리거를 당기면 가리키는 위치에 재생 바가 표시됩니다. 볼륨, 확대, 3D 켬/끔, 정면 맞춤, 설정(⚙)이 있습니다.

설정 패널은 세 페이지로 구성됩니다.

- **화면**: 밝기, 선명도, 안티앨리어싱
- **3D**: 깊이 강도, 윤곽 맞춤, 가장자리, 빈틈 채우기, 흔들림 보정, 업데이트 빈도, 창, 2D/단일 영상도 3D로
- **형식**: 투영(180°, 360°, 평면)과 배치(좌우, 상하, 단일). 파일 이름과 화면 비율로 자동 판별됩니다. 표시가 이상할 때만 직접 선택하세요 (현재 동영상에만 적용됩니다).

깊이 효과는 좌우 배치의 VR180 동영상에서 가장 잘 나타납니다.

## 문제 해결

- **"Meta Quest가 연결되어 있지 않습니다"**: Link 또는 Air Link로 Quest를 연결한 뒤 다시 시도하세요.
- **"NVIDIA GPU(GeForce RTX 30 시리즈 이상)를 찾을 수 없습니다"**: NVIDIA 드라이버를 업데이트하세요. RTX 30 시리즈 이상의 GPU가 필요합니다.
- **3D에 "사용할 수 없음"이 표시됨**: GPU 메모리가 부족할 수 있습니다. 다른 앱을 종료하세요.
- **화면이 겹치거나 나뉘어 보임**: 설정의 형식 페이지에서 투영과 배치를 선택하세요.
