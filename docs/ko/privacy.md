# 개인정보 처리방침

**Lumidepth Player VR**

- 시행일: 2026년 10월 19일
- 개정일: 2026년 10월 28일 (홈 네트워크 서버 추가)
- 제공자: mon neural
- 문의: [hello@monneural.dev](mailto:hello@monneural.dev)

이 문서는 번역본입니다. 내용에 차이가 있는 경우 [영어판](../en/privacy.md)이 우선합니다.

## 1. 수집하는 정보

당사는 개인정보, 이용 데이터, 동영상 콘텐츠를 일절 수집하지 않습니다. 앱은 당사 서버와 통신하지 않으며, 광고나 분석 기능을 포함하지 않습니다.

## 2. PC에 저장되는 데이터

다음 데이터는 사용자의 PC에만 저장되며 어디로도 전송되지 않습니다.

- 설정 (화면 및 3D 옵션, 사용자가 등록한 공유 폴더와 서버의 주소)
- 진단 로그 (동영상 파일 이름이나 위치는 포함되지 않습니다)
- 사용자의 GPU에 맞게 최적화된 AI 깊이 모델 데이터
- 동영상 목록에 표시되는 썸네일 이미지

앱을 제거하고 `%LOCALAPPDATA%\LumidepthPlayerVR` 폴더를 삭제하면 이 데이터는 모두 삭제됩니다.

## 3. Meta 플랫폼

앱은 Meta 스토어를 통해 배포되며, 구매 확인을 위해 Meta 플랫폼을 사용합니다. 이와 관련된 정보는 [Meta 개인정보처리방침](https://www.meta.com/legal/privacy-policy/)에 따라 Meta가 처리합니다. 당사는 이 정보를 받지 않습니다.

## 4. 네트워크

구매 확인 외에 앱이 연결하는 대상은 다음뿐입니다.

- 사용자가 직접 연 PC의 드라이브와 공유 폴더 (예: 홈 네트워크의 NAS)
- 사용자가 직접 등록한 서버 (WebDAV, Jellyfin)
- 홈 네트워크에서 찾은 미디어 서버 (DLNA). 찾을 때 앱은 홈 네트워크에 검색 요청(SSDP)을 보냅니다.

서버의 사용자 이름과 비밀번호는 사용자가 Windows 자격 증명 관리자에 저장한 것을 읽어서 사용합니다. 앱은 이를 저장하지 않으며 로그에도 기록하지 않습니다.

앱은 Jellyfin 서버에 이 PC를 식별하는 ID를 전달합니다 (서버의 기기 목록에 매번 새 기기가 늘지 않도록). 이 ID는 Windows 컴퓨터 ID로 만든 해시값이며, 컴퓨터 ID 자체는 보내지 않습니다.

## 5. 아동

앱은 아동으로부터 정보를 수집하지 않습니다.
