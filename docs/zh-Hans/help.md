# 帮助

**Lumidepth Player VR** 可在 Meta Quest 上播放存储在电脑或家用 NAS 中的 VR180、VR360 和 2D 视频。AI 模型会逐帧估算深度，因此转动头部时，远近物体会自然地产生位移。

## 系统要求

- Windows 10 / 11（64 位）
- NVIDIA GeForce RTX 3060 或更新型号（RTX 30 / 40 / 50 系列）
- 通过 Meta Quest Link（数据线）或 Air Link 连接的 Meta Quest 头显
- 视频：MP4、MKV、MOV、WebM。H.265 (HEVC)、H.264（最高 4K）、AV1、VP9、ProRes
- 8 至 12 位，4:2:0 / 4:2:2 / 4:4:4，HDR（HDR10、HLG）。HDR 视频将以 SDR 显示
- 在 RTX 30 / 40 系列上，4:2:2 和 ProRes 由 CPU 解码，8K 60 fps 可能无法流畅播放（RTX 50 系列由 GPU 解码）

## 快速上手

1. 在电脑上启动 Meta Quest Link 应用，并通过 Link 或 Air Link 连接 Quest。
2. 在 Quest 的“资源库”中启动 Lumidepth Player VR。
3. 列表中会显示电脑上的驱动器。如需浏览 NAS 共享文件夹，请先在 Windows 中将其映射为网络驱动器。
4. 用右扳机键选择视频即可开始播放。首次使用 3D 时，系统会针对您的电脑准备 AI，可能需要几分钟（之后即可立即使用）。

## 操作方式

| 按键 | 列表 | 播放中 |
|---|---|---|
| 右扳机键 | 选择 / 按住并移动以滚动 | 显示播放栏 / 按下按钮 |
| A | 上一级 | 返回列表 |
| B | 上一级 | 切换 3D |
| Y | – | 播放 / 暂停 |
| X | – | 显示 / 隐藏状态行 |
| 右摇杆左/右 | – | −10 秒 / +10 秒 |
| 左摇杆左/右 | – | −60 秒 / +60 秒 |
| 按下右摇杆 | – | 重置正前方 |
| 按住右握把并移动 | – | 旋转视频 |

## 播放栏与设置

播放中扣动右扳机键，播放栏会显示在您指向的位置。播放栏包含音量、缩放、3D 开/关、重置正前方和设置（⚙）。

设置面板共有三页：

- **显示**：亮度、清晰度、抗锯齿
- **3D**：3D 深度、边缘对齐、边缘、空隙填充、防抖、更新频率、窗口、2D/单画面也转 3D
- **格式**：投影（180°、360°、平面）和排列（左右、上下、单画面）。系统会根据文件名和宽高比自动识别；仅在画面显示不正常时手动选择（仅对当前视频生效）。

深度效果最适合左右排列的 VR180 视频。

## 故障排除

- **“Meta Quest 未连接。”**：请通过 Link 或 Air Link 连接 Quest 后重试。
- **“未找到 NVIDIA GPU”**：请更新 NVIDIA 驱动程序。需要 RTX 30 系列或更新的 GPU。
- **3D 显示“不可用”**：GPU 显存可能不足。请关闭其他应用。
- **画面重影或被分割**：请在设置的“格式”页中选择投影和排列。
