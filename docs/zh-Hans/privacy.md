# 隐私政策

**Lumidepth Player VR**

- 生效日期：2026 年 10 月 19 日
- 更新日期：2026 年 10 月 28 日（新增家庭网络服务器）
- 提供者：mon neural
- 联系方式：[hello@monneural.dev](mailto:hello@monneural.dev)

本文为译文。如有任何歧义，以[英文版](../en/privacy.md)为准。

## 1. 我们收集的信息

我们不收集任何个人信息、使用数据或视频内容。本应用不与我们的服务器通信，也不包含任何广告或分析功能。

## 2. 存储在您电脑上的数据

以下数据仅存储在您的电脑上，绝不会发送到任何地方：

- 设置（显示和 3D 选项，以及您登记的共享文件夹和服务器的地址）
- 诊断日志（不包含视频文件名或位置）
- 针对您的 GPU 优化的 AI 深度模型数据
- 视频列表中显示的缩略图

卸载本应用并删除文件夹 `%LOCALAPPDATA%\LumidepthPlayerVR` 即可清除上述全部数据。

## 3. Meta 平台

本应用通过 Meta 商店分发，并使用 Meta 平台验证您的购买。其中涉及的任何信息均由 Meta 依据 [Meta 隐私政策](https://www.meta.com/legal/privacy-policy/)处理。我们不会接收这些信息。

## 4. 网络

除购买验证外，本应用只连接以下对象：

- 您自己打开的电脑驱动器和共享文件夹（例如家庭网络中的 NAS）
- 您自己登记的服务器（WebDAV、Jellyfin）
- 在家庭网络中找到的媒体服务器（DLNA）。查找时，本应用会在家庭网络中发送发现请求（SSDP）。

服务器的用户名和密码从您保存在 Windows 凭据管理器中的内容读取。本应用不会保存它们，也不会写入日志。

本应用会向 Jellyfin 服务器提供一个识别此电脑的 ID，以免服务器每次都列出新设备。该 ID 是由 Windows 计算机 ID 生成的哈希值，不会发送计算机 ID 本身。

## 5. 儿童

本应用不收集儿童的信息。

## 6. 变更

本政策如有任何变更，我们将在本页面公布。
